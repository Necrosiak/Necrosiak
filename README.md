## 💬 [Steamcord](https://github.com/Necrosiak/Steamcord)
**Discord, inside Steam Game Mode.**

[![Release](https://img.shields.io/github/v/release/Necrosiak/Steamcord?style=flat-square)](https://github.com/Necrosiak/Steamcord/releases/latest)
[![Stars](https://img.shields.io/github/stars/Necrosiak/Steamcord?style=flat-square)](https://github.com/Necrosiak/Steamcord/stargazers)
[![Downloads](https://img.shields.io/github/downloads/Necrosiak/Steamcord/total?style=flat-square)](https://github.com/Necrosiak/Steamcord/releases)

- 🎙️ **Voice chat** with a live speaking ring, per-user volume and local mute, soundboard, and Discord's own sound cues
- 🖥️ **Screen sharing (Go Live)** from Gaming Mode, with your **game audio** mixed in, and watching other people's streams
- ✉️ **DMs, group DMs and server text chat**: read, reply, forward, save attachments, send a Steam screenshot
- 🕹️ **Controller push-to-talk or mute toggle**, still working while a game has focus (Steam Controller 2026)
- 🔔 **Native Steam notifications** for calls and pings, held back while you're streaming
- 📱 **QR code login** from the Discord app, and **one Discord profile per Steam account**
- 🖼️ **Expanded full-screen view**: friends and their activity, servers, chat and the current call

## ✨ What all my plugins have in common

- 🕹️ **Controller first**: everything happens in the Quick Access Menu, no keyboard, no desktop
- 🔄 **They update themselves** from GitHub, in the background (you can turn it off)
- 🌍 **9 languages**: English, French, German, Spanish, Italian, Portuguese, Dutch, Polish and Russian, following your Steam language
- 🐧 **Any Linux that runs Steam in Gaming Mode**: one build, with runtime detection instead of distro-specific assumptions
- 🤝 **They work together**: BoneCast can add your Steamcord voice call to the stream, and every plugin holds its notifications while you're live
- 🙏 **Everyone who helps is credited**, in each project's credits and release notes

## 📥 Install a plugin

1. Install [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader).
2. In Decky's settings, turn on **Developer mode**, then **Developer → Install plugin from URL**, and paste:

| Plugin | URL |
|---|---|
| 💬 Steamcord | `https://github.com/Necrosiak/Steamcord/releases/latest/download/Steamcord.zip` |
| 🗝️ SkullKey | `https://github.com/Necrosiak/SkullKey/releases/latest/download/SkullKey.zip` |
| 📡 BoneCast | `https://github.com/Necrosiak/BoneCast/releases/latest/download/BoneCast.zip` |
| 🛠️ BC250 Toolkit | `https://github.com/Necrosiak/bc250-toolkit-decky/releases/latest/download/BC250-Toolkit.zip` |

After that, each plugin keeps itself up to date. For **bc250-tweaks**, see its [quick install](https://github.com/Necrosiak/bc250-tweaks#quick-install-fresh-setup).

## 🐛 Found a bug? Have an idea?

Open an issue on the project's page, even for a small thing: many features started as someone's suggestion.
A log helps the most: each plugin writes one in `~/homebrew/logs/<plugin name>/`.
